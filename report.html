서비스 개요

SubTrackr — 은행 연동 없는 AI 구독 관리

"No bank login. No signup. Just track." / "은행 연동 없이. 가입 없이. 바로 시작."

SubTrackr는 기존 구독 관리 앱의 가장 큰 장벽인 은행 계정 연동을 제거한 서비스입니다. 스크린샷 1장이나 결제 문자를 붙여넣기만 하면 AI가 구독 정보를 자동으로 인식합니다. 데이터는 기기 로컬에 저장되어 개인정보를 보호하며, PWA 방식으로 앱 설치 없이도 사용 가능합니다. 무료(광고 지원) + 일회성 결제(광고 제거)의 단순한 비즈니스 모델을 채택하고 있습니다.

Next.js PWA AI OCR 로컬 스토리지 Google/Kakao 로그인 무료 + 일회성 결제 한국 / 글로벌

사이트 구조

  • 1
    홈 / 대시보드
    구독 목록, 월간 지출 요약, 다가오는 결제일 카드 형태 표시
  • 2
    AI 감지
    스크린샷·PDF·텍스트 업로드 → AI 자동 구독 추출. 텍스트 붙여넣기도 지원
  • 3
    구독 추가/편집
    서비스 검색(130+) or 수동 입력. 결제 주기·통화·카테고리·계정 연결 설정
  • 4
    지출 분석
    카테고리별 지출 차트, 카드/계정별 지출, 연간 절감 예상액 제공
  • 5
    캘린더 뷰
    결제 일정을 캘린더로 시각화. 7일 내 결제 예정 알림
  • 6
    설정 / 데이터
    JSON/CSV 내보내기·가져오기, 계정 연동(Google·Kakao), 광고 제거 결제

주요 기능

🤖 AI 자동 감지

스크린샷, PDF, 카드 명세 HTML, 결제 문자 텍스트를 업로드하면 구독 서비스명·금액·결제일을 자동 추출. 드래그로 수동 선택도 가능.

🔒 프라이버시 우선

은행 계정 연동 없이 작동. 비회원 시 데이터는 브라우저 로컬 스토리지에만 저장. 비밀번호는 수집하지 않음.

🌍 글로벌 다국어

한국어·영어·일본어·중국어·스페인어·포르투갈어·독일어·프랑스어·힌디어·아랍어·베트남어 11개 언어 지원. 16개 통화.

📱 PWA (앱 설치 불필요)

iOS·Android 홈 화면에 추가 가능. 결제 알림을 네이티브 앱처럼 수신. 앱스토어 없이 설치.

📊 지출 분석

카테고리별 지출 차트, 카드·계정별 분류, 월→연간 전환 시 예상 절감액(~15%) 자동 계산.

💳 단순 비즈니스 모델

무료(광고 포함) + 일회성 결제로 광고 영구 제거. "구독 없는 구독 관리 앱"이라는 일관된 메시지.

잘한 점 & 개선 제안

✅ 잘한 점

  • ✓
    명확한 차별화 — "은행 연동 없음"을 핵심 메시지로 일관되게 전달. 3단어 tagline이 경쟁 앱과 즉각적으로 구분됨.
  • ✓
    프라이버시 설계 — 비회원 로컬 저장, 비밀번호 미수집. 보안 민감 유저를 잘 공략함.
  • ✓
    AI 다양한 입력 지원 — 스크린샷·PDF·HTML명세·문자 텍스트 모두 지원. 사용자 진입 장벽이 낮음.
  • ✓
    PWA 완성도 — iOS·Android 설치 가이드까지 제공. 앱스토어 배포 없이 네이티브 앱 경험 제공.
  • ✓
    글로벌 확장성 — 11개 언어·16개 통화·hreflang 완비. 초기부터 해외 시장 고려.
  • ✓
    일관된 수익 모델 — "구독 없는 구독 관리" 메시지와 일치하는 일회성 결제. 브랜드 스토리와 완벽한 정합성.
  • ✓
    SEO 최적화 — JSON-LD, hreflang, OpenGraph, Twitter Card 모두 구현. 별점 스니펫도 노출 가능.

🔧 개선 제안

  • !
    랜딩 페이지 SSR 부재 — Next.js임에도 클라이언트 렌더링이라 초기 크롤링 시 콘텐츠가 빔. 핵심 섹션은 서버 사이드 렌더링 전환 필요.
  • !
    소셜 프루프 노출 강화 — 4.8점/120개 리뷰가 있으나 랜딩에서 충분히 부각되지 않음. 실제 사용 후기·숫자를 히어로 섹션 근처에 배치하면 전환율 향상.
  • !
    온보딩 흐름 명시화 — "스크린샷 업로드 → AI 감지 → 추가" 3단계 흐름을 랜딩에서 시각적으로 보여주면 이탈률 감소.
  • !
    서비스 목록 시각화 — 130+ 서비스 로고를 스크롤 배너로 노출하면 신뢰도·인지도 상승.
  • !
    AI 분석 월 한도 표시 — 무료 티어 한도(월 50회 등)가 명세서에 언급되나, 가격 정책 페이지가 명확하지 않음. 별도 요금제 비교 섹션 추가 권장.
  • !
    다크 모드 지원 — 테마 색상이 다크 계열임에도 라이트/다크 전환 여부가 불명확. 다크 모드 명시적 지원으로 UX 완성도 향상.
